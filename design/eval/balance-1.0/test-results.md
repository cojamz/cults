# Test results (Nov 1, 10-card deck, 4 players)

Each number is how often the owner won, against what they'd win on average with that many members.

## Guest Book ("Whenever you recruit a member of a color none of your members have, +2 yellow.") with Dabblers fixed
- Easy bots (Normal): owners won 13% before the fix, 17% after (even about 25%). 800 games.
- Hard bots: 14% before, 22% after. 200 games.
- Read: the fix helped a lot against Hard, where it's now close to even. Against easy bots it is still weak. Its +2 stays (your call). Since then four more counting faults around Dabblers and Drifters were fixed live (Big Tent, Matchmaker, Connoisseurs), which these games predate.

## Desperado (today "While you have the fewest followers (ties count), double what you steal from spaces.")
- Double (today): easy bots 23% vs 26%, Hard 31% vs 27%.
- Flat +2 more: easy bots 24% vs 25%, Hard 19% vs 25%.
- Flat +3 more: easy bots 23% vs 25%, Hard still running (too few owners so far).
- Read: every version lands about even; the differences are inside the noise (30 to 40 owners at Hard). Bots buy it in about 3 games of 10 when it shows. The flat versions don't make it weaker or stronger in a way the games can see, so the choice is about which reads better at the table.
